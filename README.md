# 🇳🇮 Hackathon Nicaragua 2026 — Onboarding Técnico

Bienvenido al repositorio de infraestructura y registro para la fase de incubación del **Hackathon Nicaragua 2026**.

## 🎯 Objetivo de la Fase I
Establecer la línea base tecnológica, dominar Git/GitHub como estándar de industria y conocer **GitHub Codespaces**.

## 📋 Proceso de Registro (Obligatorio)
Para comenzar, registra tu equipo, debes seguir el estándar de ingeniería profesional: **un Pull Request**.

### Pasos para registrarte:
1. **Hacé un Fork** de este repositorio.
2. Abrí tu fork en un **GitHub Codespace**.
3. Navegá a la carpeta `equipos/`.
4. Copiá el archivo `_plantilla.md` y crea uno nuevo con el nombre de tu equipo (ej: `equipos/mi-gran-startup.md`).
5. Llená la información requerida siguiendo el formato exacto.
6. Realiza un **Commit** con un mensaje claro (ej: `feat: registro equipo mi-gran-startup`).
7. Abre un **Pull Request (PR)** hacia la rama `main` del repositorio original.
8. Un robot (**GitHub Action**) validará automáticamente si tu registro cumple con el formato.

> [!CAUTION]
> Si el robot marca tu PR en rojo (❌), el registro NO es válido. Revisa los logs de la acción, corrige tu archivo y haz push nuevamente. El robot volverá a validar.

## 🛠️ Herramientas Sugeridas
- **GitHub Codespaces:** Entorno de desarrollo completo en la nube.
- **Git:** Control de versiones.
- **Markdown:** Para documentación técnica.
